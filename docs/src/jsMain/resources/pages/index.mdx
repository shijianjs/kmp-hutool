# kmp-hutool

Hutool's utilities, rewritten for Kotlin Multiplatform: one `commonMain` source set for the JVM,
JavaScript and WebAssembly.

**[Read the documentation](/intro)** ·
**[Try the demo](https://shijianjs.github.io/kmp-hutool/demo/)** ·
**[API reference](https://shijianjs.github.io/kmp-hutool/api/)** ·
**[GitHub](https://github.com/shijianjs/kmp-hutool)**

## Why this port

| | |
| --- | --- |
| **One source set, three targets** | Every helper lives in `commonMain` and compiles for the JVM, JavaScript and WebAssembly. |
| **Kotlin, not Java copies** | Merged facades, `kotlinx-datetime` values, explicit `toXxx` conversions and `data class` value types. |
| **No hidden dependencies** | The core depends only on `kotlinx-datetime`; larger areas stay optional. |
| **Honest coverage** | All 1557 upstream classes are inventoried; every exclusion carries a reason. |
| **Docs in two languages** | This site and the demo switch between English and Simplified Chinese. |
| **Clear licensing** | MIT for this port, Mulan PSL v2 for the upstream code it derives from. |
