<ktjs-features section-title="Why this port" tinted>

<ktjs-feature icon="lucide:layers" title="One source set, every target">Every helper lives in `commonMain` and compiles for the JVM, JavaScript, WebAssembly and Kotlin/Native, so the same call works on a server, in a browser and on a device.</ktjs-feature>

<ktjs-feature icon="lucide:code" title="Kotlin, not Java copies">Merged facades, `kotlinx-datetime` values, explicit `toXxx` conversions and `data class` value types instead of transliterated Java.</ktjs-feature>

<ktjs-feature icon="lucide:package" title="No hidden dependencies">The core depends only on `kotlinx-datetime`; larger areas stay optional, so a small consumer does not pay for them.</ktjs-feature>

<ktjs-feature icon="lucide:list-checks" title="Honest coverage">All 1557 upstream classes are inventoried; every exclusion carries a reason, and the catalogue is a page you can check instead of a promise.</ktjs-feature>

<ktjs-feature icon="lucide:globe" title="Docs in two languages">This site and the demo switch between English and Simplified Chinese.</ktjs-feature>

<ktjs-feature icon="lucide:scale" title="Clear licensing">MIT for this port, Mulan PSL v2 for the upstream code it derives from — stated per area, not glossed over.</ktjs-feature>

</ktjs-features>
