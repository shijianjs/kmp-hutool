<ktjs-features section-title="为什么做这个移植" tinted>

<ktjs-feature icon="lucide:layers" title="一套源码，所有目标">所有工具都在 `commonMain`，同时编译到 JVM、JavaScript、WebAssembly 与 Kotlin/Native：服务端、浏览器、设备上都是同一个调用。</ktjs-feature>

<ktjs-feature icon="lucide:code" title="Kotlin 写法，不是 Java 复制">合并门面、`kotlinx-datetime` 值类型、显式 `toXxx` 转换、`data class` 值对象，而不是把 Java 逐行搬运。</ktjs-feature>

<ktjs-feature icon="lucide:package" title="没有隐藏依赖">核心只依赖 `kotlinx-datetime`，更大的领域保持可选，小体量的使用方不必为它们付费。</ktjs-feature>

<ktjs-feature icon="lucide:list-checks" title="诚实的覆盖率">上游 1557 个类全部入清单，每个排除项都带理由：这是一页能逐条核对的目录，不是一句承诺。</ktjs-feature>

<ktjs-feature icon="lucide:globe" title="中英文档">本站与演示页都能在中英文之间切换。</ktjs-feature>

<ktjs-feature icon="lucide:scale" title="许可清晰">本项目 MIT，衍生自的上游代码为 Mulan PSL v2，按领域标清而不是含糊带过。</ktjs-feature>

</ktjs-features>
