# kmp-hutool

为 Kotlin Multiplatform 改写的 Hutool 工具库：JVM、JavaScript、WebAssembly 共用同一份 `commonMain` 源码。

**[阅读文档](/intro)** ·
**[在线演示](https://shijianjs.github.io/kmp-hutool/demo/)** ·
**[API 文档](https://shijianjs.github.io/kmp-hutool/api/)** ·
**[GitHub](https://github.com/shijianjs/kmp-hutool)**

## 为什么做这个移植

| | |
| --- | --- |
| **一套源码，三个目标** | 所有工具都在 `commonMain`，同时编译到 JVM、JavaScript 与 WebAssembly。 |
| **Kotlin 写法，不是 Java 复制** | 合并门面、`kotlinx-datetime` 值类型、显式 `toXxx` 转换、`data class` 值对象。 |
| **没有隐藏依赖** | 核心只依赖 `kotlinx-datetime`，更大的领域保持可选。 |
| **诚实的覆盖率** | 上游 1557 个类全部入清单，每个排除项都带理由。 |
| **中英文档** | 本站与演示页都能在中英文之间切换。 |
| **许可清晰** | 本项目 MIT，衍生自的上游代码为 Mulan PSL v2。 |
